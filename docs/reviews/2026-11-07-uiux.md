# UI/UX改善記録

## 対象と方針
既存の個人用カンバン。ブランドは木色・生成り・朱色の和風を維持し、本文はゴシック、見出しは明朝。既存React/TypeScript/CSSとAPIを利用し、新規依存は追加しない。
他セッションが利用中の主ツリーを保護するため、専用worktreeで作業した。主ツリーの開始時点の未コミット変更を引き継いでいるため、git diff HEAD全体を今回の変更と解釈しない。

## 修正
- ネイティブdialogで背景を操作対象から除外し、キーボードフォーカスを閉じ込める。終了時は元の操作へフォーカスを戻す。
- 未保存時の閉じる・Escape・ページ離脱を保護。処理中はフォームを無効化し、連打を防ぐ。
- 優先度・ラベル色は標準radioにし、矢印キーで選択可能。
- ドラッグ代替として編集画面に移動先の列を設ける。変更内容はアーカイブ時にも保存。
- カード、アーカイブ、全カードに影響するラベルの削除で確認とキャンセルを提示。
- Undo通知は時間で消さず、削除済みラベルを除外して復元する。
- 保存成功と表示更新の失敗を区別。表示更新だけ失敗した場合は保存操作を繰り返さず、再取得ボタンを提示。
- 日本語IME変換確定のEnterによる誤送信・誤改名を防止。
- 操作名をボード・カード・アーカイブへ統一。必須項目、処理中表示、空状態、再試行を明確化。
- 実際のヘッダー高に合わせて作業領域を配置。長い列名・カード名は折り返す。
- 入力欄と操作領域を拡大。ドラッグ持ち手はタッチ操作に対応。動きを減らす設定と強制カラーモードにも対応。

## 検証の限界
UIの自動テスト4件はサーバーレンダリングされたHTMLの意味構造を検証する。実ブラウザの全操作を自動検証するE2Eテストではない。375pxの確認時はエミュレーターのピンチ拡大率が1.428となっており、横幅の計測と通常幅の目視確認を併用した。実機のタッチ操作、VoiceOverによる全操作、完全なWCAG適合判定までは行っていない。
