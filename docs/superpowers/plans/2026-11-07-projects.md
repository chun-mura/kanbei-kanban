# プロジェクト作成・切り替え Implementation Plan

**Goal:** 独立したボードを持つプロジェクトを作成し、切り替えられるようにする。
**Architecture:** SQLite に projects と列・ラベルの project_id を追加する。カードは所属列を通してプロジェクトに属する。API と React Context はプロジェクト単位に固定し、切り替え時に画面を再マウントする。
**Tech Stack:** 既存の React / Hono / Drizzle / SQLite。依存追加なし。
**Spec:** 会話で承認された仕様（名前で作成、初期3列、全データ独立、既存データ引き継ぎ、最後の選択を復元、名前変更・削除は対象外）。

## Global Constraints
- 既存データは「既存のプロジェクト」に引き継ぐ。
- 初期列は「未着手」「進行中」「完了」。
- 最後の選択はブラウザの localStorage に保存する。利用できない場合もアプリは利用可能。
- 既存の墨・朱・木地の配色とCSSを継承する。

## Review Focus
- 旧DB移行と再起動でデータ・列を重複させない。
- 他プロジェクトのIDを送信しても読み書きできない。
- 並べ替え・ラベル・控えもプロジェクト内で完結する。
- 切り替え前の通信応答や元に戻す操作が切り替え先に影響しない。
- 保存済みの選択が不正・localStorageが利用不可でも起動できる。
